# Projeto ONG - Ações Sociais

Projeto web desenvolvido para uma atividade acadêmica de Desenvolvimento Front-end, com foco na criação de uma interface para apresentação de ações sociais, projetos, doações e voluntariado.

## Objetivo

Desenvolver uma aplicação web organizada, acessível e de fácil manutenção, aplicando conceitos de desenvolvimento front-end, estruturação semântica, estilização, interação e boas práticas de versionamento.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
